**# Лабораторная работа №1. Разведочный анализ данных**



**## О проекте**

**Разведочный анализ датасета Titanic: аудит качества данных и первичная визуализация.**



**## Структура проекта**

**- `data/` — исходный датасет `Titanic-Dataset.csv`**

**- `notebooks/01\\\_data\\\_understanding.ipynb` — ноутбук с анализом**

**- `report/quality\\\_report.md` — отчёт о качестве данных**



**## Как запустить**

**1. Установить зависимости: pip install pandas numpy matplotlib seaborn jupyter**

**2. Запустить Jupyter Notebook: jupyter notebook**

**3. Открыть `notebooks/01\\\_data\\\_understanding.ipynb` и выполнить все ячейки (Kernel → Restart \& Run All).**
